这次请求经过了什么

  1. 客户端在 Header 中携带可选的 X-Gray-Token。
  2. OpenResty + Lua读取 Token，并查询 Redis 白名单或路由键。
  3. 网关执行 ngx.exec("@gray") 或 ngx.exec("@normal")。
  4. 后端目标组用响应头标出自己是 normal 还是 gray。
